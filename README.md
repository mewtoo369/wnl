# 极简无广告 iPhone 万年历 (WanNianLi PWA)

一个专为 iPhone 量身打造、极致简洁、零广告、高颜值且历法数据 100% 准确的现代化万年历应用。

---

## ✨ 核心特性

- 📅 **权威历法与精准天文算法**：
  - 基于中国科学院紫金山天文台标准及 `6tail/lunar-javascript` 高精度算法引擎。
  - 公历、农历、干支纪年/月/日/时、十二生肖、二十四节气精确到分秒、传统节假日。
- 🏮 **传统老黄历精粹**：
  - 每日宜忌、冲煞方位、彭祖百忌、吉神凶煞、喜神/福神/财神方位、每日十二时辰吉凶速览。
- 🏖️ **中国法定节假日与调休**：
  - 醒目标注国务院法定节假日「休」与调休补班「班」角标，放假补班一目了然。
- 📱 **专为 iPhone 设计的 iOS 级体验**：
  - iOS 毛玻璃质感（Backdrop Blur）、平滑圆角、自适应浅色/深色（Dark Mode）模式。
  - 动态适配 iPhone 顶部灵动岛/刘海与底部安全区。
  - 支持左右滑动手势流畅切换月份。
- 🔒 **纯本地私密记事**：
  - 在任意日期随手记录备忘/待办，数据 100% 存储在手机本地 LocalStorage，不上传任何服务器，支持一键备份与恢复。
- ✈️ **100% 离线可用 (PWA)**：
  - 无需 App Store 审核，通过 Safari 添加到主屏幕即可获得无地址栏的原生 App 体验，无网络也能毫秒级秒开。

## 🚀 如何在 iPhone 上使用？

### 方式一：局域网快速体验（最快 10 秒搞定）

1. 在 Mac 终端运行本地服务脚本：
   ```bash
   python3 preview.py
   ```
2. 终端会打印出类似 `http://192.168.x.x:8080` 的局域网地址。
3. 确保你的 iPhone 与 Mac 连接在同一个 Wi-Fi 网络下。
4. 用 iPhone 的 **Safari 浏览器** 打开该地址。
5. 点击 Safari 底部中央的 **「分享」** 按钮（方框带向上箭头） -> 往下滑动点击 **「添加到主屏幕」**。
6. 回到 iPhone 桌面，即可看到万年历图标，点击即可以原生 App 形式全屏打开！

---

### 方式二：免费云端部署（随时随地全国任意网络访问）

因为本项目是纯静态前端工程（无任何后端依赖），你可以永久免费部署在以下任意平台：

- **GitHub Pages**：将代码上传到你的 GitHub 仓库，在仓库设置（Settings -> Pages）中开启 GitHub Pages 即可获得一个永久访问链接。
- **Vercel / Cloudflare Pages**：直接拖拽本文件夹即可秒级上线。
